# Sheet Metal Apprentice Test Trainer

Free bilingual (English / Russian) practice trainer for the written tests of the sheet metal apprenticeship.

**Live:** https://sergeisysoev.github.io/sheet-metal-tests/ · all tools: https://sergeisysoev.github.io/

- Questions and answer options word for word as on the tests; every answer explained.
- Drawings are redrawn as clean vector figures (`img/*.svg`, generated by `tools/figures.py`).
- Modes: practice set of 25 (mixed topics, no repeats until a topic is used up), all questions, by topic,
  by test in original order, and "My mistakes" (kept in the browser until answered right).
- Russian mode shows the English original under the translation.

Study material, not an official answer key.

## Build
`python3 tools/build_questions.py` → `questions.js` (checks English text, answers, translations, figures).
After a content change bump `questions.js?v=N` in `index.html`.
